# Agent notes

SozuPay Dashboard (this repo) is the merchant and NGO control plane at `pay.sozu.capital`. Use `CONTEXT.md` for product language. Sozu Wallet (Expo, separate repo) is the payer app; named public URLs in this repo are a contract the wallet must honor.

## Agent skills

### Issue tracker

Local markdown under `.scratch/<feature>/` (spec + one file per ticket). See `docs/agents/issue-tracker.md`.

### Triage labels

Default roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
